

تحديث جديد: أنواع الأسئلة وترتيبها
---------------------------------
الأنواع المتاحة:
1) اختيار واحد
2) اختيارات متعددة
3) إجابة قصيرة مكتوبة
4) صح أو غلط

لتحديث مشروع Supabase الموجود بالفعل:
1. افتح Supabase ثم SQL Editor.
2. افتح ملف supabase-migration-question-types.sql الموجود في الحزمة.
3. انسخ محتواه كاملًا إلى SQL Editor واضغط Run.
4. ارفع الملفات الجديدة index.html وstyle.css وscript.js إلى نفس استضافة الموقع.
5. افتح لوحة الأدمن وسجّل الدخول. عند إضافة/تعديل سؤال، اكتب رقم نوع السؤال من 1 إلى 4.
6. استخدم زري ↑ و↓ بجانب كل سؤال لترتيب الأسئلة. يتغير الترتيب الذي يظهر به السؤال في الاختبارات الجديدة.
الاختبارات القديمة تحتفظ بنسخة الأسئلة الموجودة وقت إنشائها.

مهم:
- نفّذ ملف الترحيل مرة واحدة فقط على قاعدة البيانات الحالية.
- احتفظ بقيم SUPABASE_URL وSUPABASE_ANON_KEY الصحيحة في script.js عند رفعه، ولا تستبدلها بقيم تجريبية.
- لا تشارك رابط النتائج الخاص الذي يحتوي على owner token.
